# @swmansion/gesture-handler-core

Platform-agnostic core of gesture-handler: the v3 hooks, detector
orchestration, shared types and the platform-port contract. Platform bindings
(react-native-gesture-handler, react-gesture-handler) supply a runtime that
implements the port; this package never imports react-native.

Internal package of the gesture-handler monorepo — not intended for direct
consumption.
